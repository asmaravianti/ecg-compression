🔬 Evaluation Methodology

The performance of each submission is evaluated based on the following metrics. Higher compression ratio (CR) is better for storage/transmission efficiency, while lower percentage root mean square difference (PRD) indicates more accurate signal reconstruction. Finally, an overall score balances both factors.

📐 1. Compression Ratio (CR)

Definition: The ratio of the original signal length to the compressed signal length. This metric measures how efficiently your algorithm compresses the ECG data.

Compression Ratio Formula - Higher values indicate better compression efficiency

🎯 Goal: Higher CR values indicate better compression efficiency. Top performers achieve ratios above 40:1 while maintaining signal quality.

📊 2. Percentage Root Mean Square Difference (PRD)

Definition: The error percentage between the reconstructed signal and the original signal, normalized by the signal's variability. This measures reconstruction accuracy.

Percentage Root Mean Square Difference Formula - Lower values indicate better signal quality

🔍 Formula Components:

  • fᵢ: Original signal value at point i
  • f̂ᵢ: Reconstructed signal value at point i
  • f̄: Mean value of the original signal
  • N: Total number of data points

🎯 Goal: Lower PRD values indicate better reconstruction quality. Elite algorithms achieve PRD values below 3% while maintaining high compression ratios.

🏅 3. Overall Score

Definition: A combined score that balances compression efficiency and reconstruction accuracy. This is the primary ranking metric for the leaderboard.

Score = CR / (PRD + ε)

where ε is a small constant (1×10⁻⁶) to avoid division by zero

🎯 Goal: Higher scores indicate better overall performance. The optimal algorithm maximizes compression while minimizing reconstruction error.

⚙️ 4. Evaluation Process

📥 Step 1: Input Data

Participants are provided with ECG signals in .mat format (e.g., PhysioNet_MITBIH_rec117_5min.mat). Each file contains a single ECG recording sampled at 360 Hz with 5-minute duration.

📤 Step 2: Output Requirements

Participants must submit a compressed signal and a reconstructed signal. The output files must be in .mat format and include:

  • f_recon: The reconstructed ECG signal
  • CR_val: The compression ratio

🧮 Step 3: Scoring

The scoring program computes the CR and PRD for each submission. The Overall Score is calculated as:

Score = CR / (PRD + ε)

The final score is the average score across all datasets in the test suite.

🏆 Step 4: Leaderboard

Submissions are ranked based on the Overall Score. Detailed results (including CR and PRD) are displayed for each dataset, providing comprehensive performance insights.
